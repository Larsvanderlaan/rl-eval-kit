# IRL GenPQR NeurIPS Reproducibility Folder

This folder contains the compact code and paper-visible artifacts needed to
reproduce the GenPQR/DeepPQR experiments in the NeurIPS paper draft. It omits
raw run outputs, exploratory scripts, notebooks, old drafts, virtual
environments, caches, and related-work material.

The commands below were verified with Python 3.10.14. `requirements.txt` pins
the package versions used for the verification runs.

## Contents

- `data_generation.py`, `policy_estimation.py`, `q_evaluation.py`,
  `reward_recovery.py`, `utils.py`, `deeppqr_baseline.py`, and
  `lightgbm_fqe.py`: core GenPQR/DeepPQR implementation.
- `experiments/run_paper_experiments.py`: reproduces the main matched
  DeepPQR-vs-GenPQR comparison and the high-sample method comparison.
- `experiments/action_scaling_runner.py`: reproduces the many-action appendix
  figure.
- `experiments/data_fusion_large_action_runner.py`: reproduces the 20-action
  complementary-source experiment.
- `paper_artifacts/`: the five external graphics included in the NeurIPS
  paper source.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Reproduce The Paper Experiments

From this folder, run:

```bash
python experiments/run_paper_experiments.py --replicates 100 --jobs 4 --output-dir outputs/paper_run_100
python experiments/action_scaling_runner.py --replicates 100 --jobs 4 --output-dir outputs/action_scaling_100
python experiments/data_fusion_large_action_runner.py --stage confirmatory --jobs 4 --output-dir outputs/data_fusion_confirmatory
```

The scripts write raw CSVs, summaries, and regenerated plots under `outputs/`.
Those generated files are useful for auditing a run, but they are not part of
the distributed paper artifact set.

## Complementary-Source Large-Action Experiment

`experiments/data_fusion_large_action_runner.py` implements the 20-action
data-fusion study. It generates two independent views of one shared MDP:

- a state-outcome source `(S, Y)` with the latent actions withheld;
- a state-action-transition source `(S, A, S')` with rewards withheld.

The true reward retains the zero-reward anchor action used by DeepPQR. GenPQR
additionally estimates the behavior-policy normalization
`g(s) = E[Y | S=s]` from the outcome source.

Run the targeted tests and the full confirmatory configuration with:

```bash
python -m pytest tests/test_data_fusion.py -q
python experiments/data_fusion_large_action_runner.py \
  --stage confirmatory \
  --jobs 4 \
  --output-dir experiments/outputs/data_fusion_confirmatory
```

The runner uses fresh stage-specific seeds, deterministic component seeds,
per-seed atomic checkpoints, and source-code fingerprints that prevent
resuming with a different implementation. The completed July 25, 2026 run is
summarized in `DATA_FUSION_EXPERIMENT.md`.
